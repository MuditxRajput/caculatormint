# GLI-2012 implementation attribution

The coefficient tables, spline lookups, and LMS equation implementation in this
folder are adapted from [@automate-medical/gli2012](https://github.com/Automate-Medical/gli2012)
(MIT License, Automate Medical Inc.).

The underlying reference equations are from the Global Lung Function Initiative
(GLI-2012 / ERS Task Force). CalculatorMint uses them for educational spirometry
interpretation tools only — not as a substitute for validated PFT software or
clinical judgment.
